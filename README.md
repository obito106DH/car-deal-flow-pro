# Kasra Motors

پلتفرم یکپارچه‌ی خرید و فروش خودرو، خرید اقساطی و تنظیم قرارداد، معامله‌ی امن حواله، بیمه و خدمات پس از فروش، فروش قطعات مصرفی و یدکی و سفارش قطعات کمیاب.

## اجرای پروژه

به Node.js 20 یا جدیدتر نیاز دارید.

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی نهایی:

```bash
npm run build
```

## بخش‌های اصلی

- خرید و فروش خودروی کارشناسی‌شده
- محاسبه اقساط و درخواست قرارداد تأمین مالی
- خرید و فروش حواله خودروهای ایرانی و وارداتی
- بیمه، سرویس دوره‌ای و خدمات پس از فروش
- فروشگاه قطعات مصرفی و یدکی و سفارش قطعه کمیاب

این پروژه با TanStack Start، React، TypeScript و Tailwind CSS ساخته شده است.
